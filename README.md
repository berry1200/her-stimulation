# her-stimulation

Virtual robotic laboratory for HER electrocatalyst testing (ROS 2 Jazzy + Gazebo Harmonic).

- `her_robot_sim_v2.zip`: the ROS 2 simulation package (see the README inside the archive)
- [`video_pipeline/`](video_pipeline/README.md): record the simulation and turn it into an edited,
  captioned video with Claude Opus 5.5 + ffmpeg
